# 更新紀錄

## 2026-08-17
- 增量 ASR 的分句庫從 PySBD 切換到 yasbd-lib (#37): API 相容無行為變化, 新增韓語等 17 種語言的原生分句規則 (此前韓語回退英語規則), 長文字分割速度大幅提升
- 修復 DeepSeek 預設開啟思考模式導致翻譯返回空、介面顯示原文的問題 (#38): DeepSeek 需要 thinking.type=disabled 才能關閉思考, 此前傳送的 enable_thinking=false 是 Qwen 風格引數對其無效; 模型編輯對話方塊新增「禁用思考」風格選擇 (自動識別 / DeepSeek·火山方舟·GLM / Qwen·百鍊·矽基流動 / vLLM·SGLang 自部署 / OpenAI·Grok reasoning_effort / 不傳送), 自動識別對 OpenAI 等會拒絕未知引數的官方端點不再亂髮引數; 思考耗盡 token 返回空時輸出診斷紀錄
- 修復高 DPI 縮放 (150%+) 下設定視窗超出螢幕、確定/取消按鈕點不到的問題 (#39): 模型編輯對話方塊與控制面板各分頁改為按需滾動, 視窗高度自動限制在螢幕可用範圍內
- 安裝與更新不再向系統盤寫入下載快取: 便攜版的 uv 快取和託管 Python 移入程式目錄, install/update 指令碼的 pip 快取與臨時檔案移入專案目錄, 裝完自動清理

## 2026-07-11
- 修復 Fun-ASR-Nano 首次載入時 Qwen3-0.6B 權重下載被 180 秒逾時打斷的問題 (#32): 權重改為在模型下載階段提前獲取, ASR worker 啟動不再等待大檔案下載
- 修復 ModelScope 1.38+ 快取位置變化導致模型漏檢的問題 (#32, #33): 相容各版本 SDK 的全部快取目錄佈局, 升級 SDK 後不再重複下載已有模型
- Qwen3-0.6B 權重支援從 ModelScope 下載, ModelScope 源使用者不再被迫走 HuggingFace (#33)

## 2026-06-20
- 新增「遠端 Whisper」ASR 引擎: 把語音識別外包到帶 GPU 的另一臺機器 (附 `asr_server.py` 服務端), 無 GPU 的機器也能即時識別
- 新增「WebID 身份核驗」翻譯提示詞預設: 針對影片核驗場景調優用詞
- ASR 改為子程序隔離執行: worker 崩潰/逾時自動重新啟動, 記憶體增長到閾值自動回收, 識別故障不再拖垮介面
- 字幕視窗支援滑鼠穿透 (#28): 字幕設定裡新增開關, 系統匣選單可「字幕滑鼠穿透」快速切換, 開啟後點擊直達背後視窗 (此時中鍵拖動失效, 先關穿透再移動)

## 2026-05-10
- 新增「匯出到檔案」: 支援原文 / 譯文 / 原文+譯文 三種格式, 懸浮窗右鍵選單與系統匣選單均可觸發
- 新增「逐字稿儲存」(預設開啟): 每次會話自動在 `transcripts/` 下建立 3 份檔案 (原文 / 譯文 / 全部), 每段識別結果即時追加寫入, 不再受懸浮窗 50 條上限丟失早期文字
- 設定面板「快取」標籤新增「逐字稿儲存」分組: 開關 + 開啟轉錄資料夾按鈕
- 新增記憶體佔用上限保護: RSS 超過 4096MB 時彈系統匣通知提示重新啟動 (ASR 後端存在 native 側工作區/快取, Python GC 與 `torch.cuda.empty_cache` 不一定能回收)
- 紀錄新增 `MEM[asr#/tick]` 行: 每次真實 ASR 呼叫後輸出 RSS / GPU(alloc/reserved) / 音訊時長 / overlay 訊息數 / VAD buffer 長度, 便於排查記憶體問題
