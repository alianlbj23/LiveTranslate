# 更新日志

## 2026-10-22
- 正式入口改成 LiveTranslate.exe，平常使用不会出现命令行：第一次打开显示安装窗口（自动安装 Python、Git、Ollama、依赖包与语音模型），之后直接启动；原来的命令行启动器与菜单移除，另附「LiveTranslate（除錯）.bat」用于排查问题（安装包不附）
- 本地翻译模型改由主程序自己管理：启动时自动打开 Ollama、缺模型时询问并显示下载进度、检查显存；退出时卸载模型并关闭 Ollama；远程／局域网的 Ollama 不会被当成本地
- 按显卡推荐模型：设置 → 翻译 →「本地翻译模型」标注【推荐】【接近上限】【显卡可能不够】，可一键下载并使用；首次安装按显卡挑选识别与翻译模型
- 设置首页新增「维护」：检查环境（显卡驱动、PyTorch／CTranslate2 CUDA、Ollama、翻译测试，结果可复制）、检查更新、打开最佳组合评测
- 程序内更新：启动后在后台检查，有新版本只通知，点「更新并重新启动」才下载安装；安装包版本也能更新（从 GitHub Releases 下载并校验压缩包），模型、设置与日志会保留
- 最佳组合评测改成窗口：问题用对话框、进度显示在窗口、可以停止与重新打开 LiveTranslate
- 悬浮窗始终显示在任务栏，新增最小化按钮，最小化／还原有系统动画；左键点托盘图标可切换最小化／唤回
- 打包修复：安装包之前漏掉的「快速開始.md」补回

## 2026-10-21
- 新增图形化启动窗口（LiveTranslate.bat）：第一次双击会自动安装，每次启动自动检查更新，可以在列表中选翻译模型（显示是否已下载与大小）；原来的三个 .bat 合并成单一入口，文字菜单保留作为备用
- 界面改成 Win11 Fluent 风格：控制面板与对话记录窗口改为卡片外观，对话记录窗口可以上下拉伸；新增「最低语音比例」设置与「恢复出厂设置」
- 字幕窗口：左键拖动、拖左右边缘调整宽度并自动换行、拖上下边缘调整高度；可以选择显示原文、译文或两者，也可以只显示最新一句；新增「固定位置」与「鼠标穿透」（双击锁定）
- 实时预览（边讲边翻）：还没讲完的句子会先显示并临时翻译，原文只增不减、译文逐字出现，像 YouTube 字幕；增量识别间隔降到 0.5 秒，字幕最短显示时间可以设置，排队中的句子不再被丢弃
- 翻译：输出一律为繁体中文与台湾用语；加入 SakuraLLM（GalTransl 7B v3.7）；启动时先让翻译模型预热；修复翻译无声卡死（流式输出设硬上限、本地模型不重试、排队太多时提示、卡住时记录所有线程状态）
- 显卡：关闭时自动卸载 Ollama 模型并关闭启动器开的 Ollama；窗口被直接关掉或程序崩溃时，显卡看门狗也会释放；状态栏的 CPU / RAM / GPU 改成测量实际干活的进程
- 指定识别语言：Fun-ASR-Nano / MLT-Nano 改用模型看得懂的语言名称；识别成其他语言的句子会逐句丢弃；句子连续或经常被丢弃、或识别连续出错时，会弹出托盘通知
- 新增「最佳组合评测」（启动窗口 → 最佳组合评测）：用公开的日语语音数据比较 4 个识别模型与各个翻译模型，测量准确度、延迟、显存，并由多个模型交叉评审翻译质量，推荐看动画与 VTuber 时的组合；选好后可以应用（应用前会先备份设置）
- 其他：Whisper 幻觉过滤、语音检测改为固定 0.5 秒停顿、Ollama 使用 KV 量化与省内存参数

## 2026-08-17
- 增量 ASR 的分句库从 PySBD 切换到 yasbd-lib (#37): API 兼容无行为变化, 新增韩语等 17 种语言的原生分句规则 (此前韩语回退英语规则), 长文本分割速度大幅提升
- 修复 DeepSeek 默认开启思考模式导致翻译返回空、界面显示原文的问题 (#38): DeepSeek 需要 thinking.type=disabled 才能关闭思考, 此前发送的 enable_thinking=false 是 Qwen 风格参数对其无效; 模型编辑对话框新增「禁用思考」风格选择 (自动识别 / DeepSeek·火山方舟·GLM / Qwen·百炼·硅基流动 / vLLM·SGLang 自部署 / OpenAI·Grok reasoning_effort / 不发送), 自动识别对 OpenAI 等会拒绝未知参数的官方端点不再乱发参数; 思考耗尽 token 返回空时输出诊断日志
- 修复高 DPI 缩放 (150%+) 下设置窗口超出屏幕、确定/取消按钮点不到的问题 (#39): 模型编辑对话框与控制面板各标签页改为按需滚动, 窗口高度自动限制在屏幕可用范围内
- 安装与更新不再向系统盘写入下载缓存: 便携版的 uv 缓存和托管 Python 移入程序目录, install/update 脚本的 pip 缓存与临时文件移入项目目录, 装完自动清理

## 2026-07-11
- 修复 Fun-ASR-Nano 首次加载时 Qwen3-0.6B 权重下载被 180 秒超时打断的问题 (#32): 权重改为在模型下载阶段提前获取, ASR worker 启动不再等待大文件下载
- 修复 ModelScope 1.38+ 缓存位置变化导致模型漏检的问题 (#32, #33): 兼容各版本 SDK 的全部缓存目录布局, 升级 SDK 后不再重复下载已有模型
- Qwen3-0.6B 权重支持从 ModelScope 下载, ModelScope 源用户不再被迫走 HuggingFace (#33)

## 2026-06-20
- 新增「远程 Whisper」ASR 引擎: 把语音识别外包到带 GPU 的另一台机器 (附 `asr_server.py` 服务端), 无 GPU 的机器也能实时识别
- 新增「WebID 身份核验」翻译提示词预设: 针对视频核验场景调优用词
- ASR 改为子进程隔离运行: worker 崩溃/超时自动重启, 内存增长到阈值自动回收, 识别故障不再拖垮界面
- 字幕窗口支持鼠标穿透 (#28): 字幕设置里新增开关, 托盘菜单可「字幕鼠标穿透」快速切换, 开启后点击直达背后窗口 (此时中键拖动失效, 先关穿透再移动)

## 2026-05-10
- 新增「导出到文件」: 支持原文 / 译文 / 原文+译文 三种格式, 悬浮窗右键菜单与托盘菜单均可触发
- 新增「转录持久化」(默认开启): 每次会话自动在 `transcripts/` 下创建 3 份文件 (原文 / 译文 / 全部), 每段识别结果实时追加写入, 不再受悬浮窗 50 条上限丢失早期文本
- 设置面板「缓存」标签新增「转录持久化」分组: 开关 + 打开转录文件夹按钮
- 新增内存占用上限保护: RSS 超过 4096MB 时弹托盘通知提示重启 (ASR 后端存在 native 侧工作区/缓存, Python GC 与 `torch.cuda.empty_cache` 不一定能回收)
